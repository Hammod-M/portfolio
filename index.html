How I work

1

Business goal first

Before coding I find out why the task matters, split it into small releases and agree on the API with backend developers early.

2

TypeScript and tests

Strict TypeScript, Vitest and Playwright. When I fix a bug, I add a test so it does not come back.

3

AI helps, I own the code

I use AI coding agents every day, but I plan the change myself, read every diff and let CI checks catch mistakes.

4

Thinking about production

Monitoring, alerts and an honest “no data” instead of a zero — users should never see a wrong number.
